## Спільні чинники (обидві сторони)

**Bolt (системно)**

- Немає пікап-коду на Копійці → немає незалежного підтвердження видачі.
- Кур’єри з нулем доставок у житті могли брати high-value 18+.
- CS-причина «closed» накладається на стейт `waiting_pickup`.
- Fail + `is_provider_paid = false` — правильний стейт **за аппом**, але не доводить, що товар лишився в магазині.

**Партнер (операційно)**

- Ready / POS-чек без акту одержувача.
- 18+ і унікальні пляшки (Macallan, Dom Pérignon) без верифікації.
- Немає CCTV у момент претензії.
- На HQPGG власна версія для CS була OOS — це не «кур’єр точно забрав».

Базовий фон тих самих двох точок за червень–липень: сотні звичайних delivered-ордерів із середнім чеком ~18 €. Ці шість — хвіст 150–424 €. Тобто мережа в цілому працює; спір сидить на high-value без коду видачі.
